# Site Portfólio — João Victor

Landing em React + TypeScript. TaskFlow (API + frontend local) aparece em destaque; ShortLink é um full-stack menor; Tip Calculator é um frontend local com screenshot da UI no card. Os cards descrevem stack e status reais (o dashboard do YouTube segue como frontend em evolução). Este repo não publica GitHub Pages.

![Screenshot do site](docs/screenshot.png)

Versão publicada do currículo:
https://github.com/dev-joaovictor/curriculo  
https://dev-joaovictor.github.io/curriculo/

## Rodar

```bash
npm install
npm run dev
```

Dados em `src/data/projects.ts`. Para build de verificação: `npm run build`.
