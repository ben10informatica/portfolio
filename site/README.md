# Site Portfólio — João Victor

Landing page em React + TypeScript para apresentar projetos e skills.

## Stack

- React 18
- TypeScript
- Vite

## Como rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`

## Dados pessoais

Tudo fica em `src/data/projects.ts`:

- Nome, bio e seção Sobre
- `email`, `github` e `linkedin` — GitHub já aponta para https://github.com/ben10informatica
- Lista de projetos

## Deploy

```bash
npm run build
```

Suba a pasta `dist/` na Vercel ou Netlify.
